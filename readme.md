# Freight Rate Prediction

**Machine Learning Engineer Assessment — Spotter, Inc.**

Predicts US truckload spot freight rates from route, equipment, weight, and date features.
Trained on 48,000 labeled loads (Jan–Oct 2025), evaluated on a time-based holdout
(Sep–Oct 2025), and deployed to predict 12,000 validation loads (Nov–Dec 2025)
plus a fixed December daily rate forecast.

| Metric | Holdout (Sep–Oct 2025, n = 9,523) |
|--------|-----------------------------------|
| MAE    | $118.82                           |
| RMSE   | $636.85                           |
| MAPE   | 5.20 %                            |
| R²     | 0.826                             |

**Model:** `HistGradientBoostingRegressor` with absolute-error (L1) loss
— selected over Ridge Regression, Random Forest, Gradient Boosting, and
HistGBR (squared loss) on the same holdout.

## Quickstart — Reproduce All Results

### Step 1 — Train and predict

```bash
python train.py
```

This will:
- Clean the training data (fix sign-flip weight errors, impute missing values)
- Evaluate the model on a time-based holdout (train Jan–Aug 2025, holdout Sep–Oct 2025)
- Print MAE / RMSE / MAPE / R² to the terminal
- Save metrics to `reports/holdout_metrics.json`
- Refit the final model on all 48,000 labeled rows
- Write `validation_predictions.csv` (12,000 rows)
- Write `december_predictions.csv` (31 rows)

Expected terminal output:
```
Evaluating on time-based holdout (train < 2025-09-01, holdout >= 2025-09-01)...
  n_train: 38477
  n_holdout: 9523
  mae: 118.82
  rmse: 636.85
  mape: 0.0520
  r2: 0.8258

Refitting final model on all labeled data (Jan-Oct 2025)...
Predicting validation.csv -> validation_predictions.csv
Predicting december-chart-inputs.csv -> december_predictions.csv

Done.
```

### Step 2 — Validate output files and generate December chart

```bash
python score.py --predictions validation_predictions.csv \
                --december-predictions december_predictions.csv
```

Expected output:
```
Validated 12,000 final predictions.
Validated 31 fixed December predictions.
Created chart: scorer_results\candidate_december.png
```

## Approach Summary

### Why time-based split?

The validation set spans Nov–Dec 2025 — months the model has never seen.
A random K-fold split would allow the model to interpolate between dates seen
on both sides of each fold, artificially inflating accuracy.
A time-based holdout (train Jan–Aug, evaluate Sep–Oct) mirrors the actual
extrapolation the model must perform and gives a realistic accuracy estimate.

### Why HistGradientBoostingRegressor with absolute-error loss?

Five models were compared on the same holdout:

| Model | MAE ($) | RMSE ($) | MAPE (%) | R² |
|-------|---------|----------|----------|----|
| Ridge Regression | 185.6 | 654.4 | 9.48 | 0.8161 |
| Random Forest | 191.8 | 698.0 | 8.29 | 0.7908 |
| Gradient Boosting | 148.6 | 660.6 | 6.46 | 0.8126 |
| HistGBR (squared loss) | 132.5 | 637.5 | 6.06 | 0.8255 |
| **HistGBR (absolute loss) ✓** | **119.2** | **637.1** | **5.24** | **0.8257** |

HistGBR with L1 loss was selected because:
- Best MAE and MAPE on the holdout
- L1 loss is robust to the 0.66% high-rate outlier tail in the data
- Natively handles missing values (no explicit imputation pipeline needed)
- ~5× faster than standard Gradient Boosting via histogram binning

### Key feature decisions

- **`distance`** — strongest predictor (Pearson r = 0.91); used as-is per shipment
- **Lat/lon over city names** — 8 validation cities are unseen in training; continuous coordinates generalise to new locations
- **Cyclical sin/cos date encodings** — tree models cannot extrapolate beyond training range; sin/cos ensures December values stay inside the training distribution
- **`market_index` and `quote_signal` excluded** — negligible correlation with target (|r| < 0.05), absent from the December inputs, and ablation showed <1% MAE impact

### Data quality issues found and fixed

| Issue | Rows | Fix |
|-------|------|-----|
| Negative weight (sign-flip errors) | 292 (0.61%) | `abs(weight)` in `src/features.py` |
| Missing weight | 300 train / 165 val | Median imputation (training split only) |
| Missing market_index | 374 train / 249 val | Feature excluded entirely |
| Unseen cities in validation | 8 cities | Lat/lon features instead of city names |

and prediction files.
